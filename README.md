# jane-natividad.github.io

The source for my portfolio site, **[jane-natividad.github.io](https://jane-natividad.github.io)**.

I'm Jane Natividad, and I work across healthcare product, program and portfolio strategy. I like to learn by building. Each project below began with a real problem I ran into or watched a team wrestle with. I scoped it small enough to build myself and turned it into a working prototype you can try in your browser.
